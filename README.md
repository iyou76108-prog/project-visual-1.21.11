# PROJECT VISUAL

A performance-first visual client for Minecraft 1.21.11 on Fabric.

## Status

Initial project setup is being prepared. The first milestone will focus on a lightweight HUD, ClickGUI foundation, and configurable visual modules.

## Target

- Minecraft Java Edition 1.21.11
- Fabric Loader
- Java 21
- FPS-first rendering and bounded particle workloads

## Build

The Gradle wrapper and build instructions will be added with the initial source scaffold.
